# 暦かさね

西暦（グレゴリオ暦）と旧暦の参考表示を併記する、ビルド不要の小さなカレンダーアプリです。

## 開き方

現時点では Node.js は不要です。`index.html` をブラウザで開いてください。

ローカルサーバー経由で開く場合は、PowerShell で次を実行します。

```powershell
.\serve.ps1
```

続いて `http://localhost:8000` を開きます。

## 現在の設計

- `index.html`: 画面の意味・構造
- `styles.css`: 見た目とレスポンシブ表示
- `app.js`: 状態管理、月移動、旧暦表示

旧暦変換は `Intl.DateTimeFormat('zh-CN-u-ca-chinese')` を利用しています。依存関係を増やさず学習用の最小実装にするためです。ただしこれは日本の天保暦系の旧暦を保証するものではありません。祭事、法務、商用など正確性が要る用途では、対象期間・採用暦法・`Asia/Tokyo` を要件として固定し、検証済みの日本旧暦ライブラリまたは信頼できる暦データに差し替え、代表日・閏月境界の自動テストを追加してください。

## AI に依頼するときの例

```text
このリポジトリの旧暦カレンダーを改善したい。

目的: 日本の旧暦と西暦を月表示で併記する。
制約: フレームワークは導入しない。表示は日本語。タイムゾーンは Asia/Tokyo。
完了条件:
- 前月・次月・今日へ戻る操作ができる
- 日付を選択すると西暦と旧暦の詳細を表示する
- スマートフォン幅でも崩れない
- 旧暦の定義と対応範囲を README に明記する

まず実装案・変更予定ファイル・検証方法を短く示し、了承後に実装して。
実装後は変更内容、実行した検証、残る制約を報告して。
```

## 学習用の進め方

1. 1つの小さい要求だけを依頼する（例: 「選択日の色を変える」）。
2. 実装前に、対象ファイルと受け入れ条件を確認する。
3. ブラウザで実際に操作し、意図した動きか確認する。
4. 意味のあるまとまりごとに Git commit を作る。

```powershell
git add index.html styles.css app.js README.md
git commit -m "旧暦併記カレンダーの初期版を追加"
```
