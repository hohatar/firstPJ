# コンテンツ編集者ガイド

## 状態

下書き段階。microCMS設定後に画面キャプチャを追加する。

## 想定する公開手順

1. microCMSへログインする。
2. 対象のコンテンツを新規作成または編集する。
3. 下書きを保存し、文章、リンク、画像を確認する。
4. コンテンツを公開する。
5. Cloudflare Pagesのビルド完了を待つ。
6. 公開ページを開き、結果を確認する。

## 製品移行の手順

1. [microcms/schemas/README.md](../microcms/schemas/README.md)の作成順に、API名・エンドポイント・形式を入力してJSONスキーマをインポートする。
2. 製品APIでは、インポート後に`category`、`gallery`、`documents`、`specifications`を[スキーマ手順](../microcms/schemas/README.md)に従って追加する。
3. 製品カテゴリを作成または確認する。
4. 型番、カテゴリ、中国語・日本語・英語の名称、画像、説明、仕様を持つ製品を作成する。
5. 翻訳が未承認の場合は公開せず、下書きのまま保持する。
6. 画像と資料が公開許可済みであることを確認する。
7. Previewデプロイで中国語（ルート直下）、日本語（`/ja/`）、英語（`/en/`）のカテゴリページと製品詳細ページを確認する。
8. 製品責任者が技術的正確性を確認してから公開する。

## 編集ルール

- 中国語・日本語・英語それぞれで、内容と表記の承認を得たタイトルを使用する。
- 中国語はルート直下を正規URLとし、`/zh/`配下は既存リンクのための互換URLである。編集後は言語切替先と正規中国語URLを確認する。
- 未確認の連絡先、価格、法的表現を公開してはならない。
- 情報を伝える画像には代替テキストを用意する。
- 組織が公開を許可された画像だけを使う。
- 公開済みコンテンツを削除する前にサイト所有者へ確認する。
- 型番、技術仕様、連絡先、法的表現は、事業責任者の確認なく変更してはならない。
- 公開・非公開は、microCMSのコンテンツ公開ステータスで管理する。独自の公開フラグは使用しない。
