# AI駆動開発の進め方

## 基本手順

1. エージェントには一度に1つの明確な成果を依頼する。
2. 編集前に関連文書を読むよう依頼する。
3. 複数ファイルや外部設定に影響する場合は、実装前に計画を求める。
4. 変更を受け入れる前に差分を確認する。
5. 完了と見なす前にビルドとテスト結果を求める。
6. 実際に同じ問題が繰り返された後でのみ、`AGENTS.md`へルールを追加する。

## プロンプト例

```text
AGENTS.mdとdocs/content-model.mdを読んでください。News APIをAstroへ連携する方法を提案してください。まだ実装はしないでください。
```

```text
承認済みのNews一覧ページを実装してください。既存規約を守り、HTML以外のコードには日本語注釈を追加し、必要な検査を実行して、差分を報告してください。
```

```text
現在の差分を、セキュリティ、アクセシビリティ、静的ホスティング制約、想定外のコストリスクの観点でレビューしてください。ファイルは変更しないでください。
```

## Skillを作るタイミング

手順が安定した作業を複数回繰り返した後にのみ、リポジトリ用Skillを作る。Skillの指示は短く、手順中心にする。
