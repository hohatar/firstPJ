# コンテンツモデル

## 状態

下書き段階。情報設計の承認後にmicroCMS APIを作成する。

## 3言語対応

公開言語は中国語（`zh`）、日本語（`ja`）、英語（`en`）とする。言語依存の項目は、microCMS上で`nameZh`、`nameJa`、`nameEn`のように言語別フィールドを持たせる。型番、製品画像、添付資料、表示順は共通フィールドとする。公開制御はmicroCMSのコンテンツ公開ステータスだけで行う。

実際に作成するAPIと全項目の正本は、[microcms-api-schema.csv](./microcms-api-schema.csv)を参照する。旧サイトから取得したデータは中国語を原文として保存し、日本語・英語は承認済みの翻訳を入力してから公開する。

## ルール

- 公開用途を文書化せずに項目を追加してはならない。
- 深いネストより単純な項目を優先する。
- 秘密情報や顧客の個人情報をmicroCMSに保存してはならない。
- 正確性と公開許可を確認するまで、製品、画像、資料、連絡先を移行してはならない。
