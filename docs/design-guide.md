# デザイン方針

## 目的

精密性、信頼性、技術力、長期的な安心感を伝える、現代的な工業・技術系サイトを作る。

## ビジュアル原則

- 旧サイトの固定幅レイアウト、言語選択ポップアップ、旧式の視覚効果は再現しない。
- 技術系のベースカラーと控えめなアクセントカラーを用いた、落ち着きのある高コントラスト配色にする。
- 十分な余白と明確な読む順序を作る。
- 中国語、日本語、ラテン文字を安定して表示できる現代的なサンセリフ体を使う。
- 利用可能な場合は、高品質な製品写真、技術図、簡潔な仕様を使用する。
- 動きは理解やフィードバックを改善する場合にのみ使う。

## ページの優先事項

1. 静電気対策に関する会社の専門性を説明する。
2. 利用者が適切な製品カテゴリを素早く探せるようにする。
3. 型番、主要仕様、製品資料を読み取りやすくする。
4. すべてのページで連絡先を見つけやすくする。

## アクセシビリティ要件

- WCAG AAのコントラスト要件を満たす。
- 意味を持つ画像に代替テキストを提供する。
- キーボード操作と見えるフォーカス状態を提供する。
- 色だけに依存して情報を伝えない。
- 自動再生コンテンツや利用者を妨げるモーダルを避ける。

## 未確定事項

- 承認済みロゴとカラーパレット。
- 優先言語と公開時の対応言語。
- 製品写真と技術資料の利用可否。
- 技術イラストを新規作成するか。
