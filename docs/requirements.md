# 要件

## 状態

下書き段階。実装前にすべての項目を確認する。

## 目的

非エンジニアがmicroCMSで更新できる、高速でアクセシブルな多言語対応可能な公開サイトを提供する。

このサイトは、静電気除去装置および静電気対策製品の研究、開発、製造、販売を行う北京亚司达科技发展有限公司（株式会社エイエスディー）を対象とする。

## デザイン方針

- 既存のレイアウト、装飾、操作パターンは引き継がず、ビジュアルデザインを全面刷新する。
- 信頼性、精密性、安全性、技術力が伝わる現代的な工業・技術系の印象を作る。
- 明確な情報階層、十分な余白、読みやすい文字、高品質な製品画像、控えめな動きを用いる。
- 会社背景、技術的強み、製品仕様、連絡先、一貫した日本語または中国語表現を信頼要素として扱う。
- 実装前にブランドカラー、ロゴ、優先言語、写真の利用権を確認する。

## 対象範囲

- 静的な公開ページ
- 会社・技術紹介
- 製品カテゴリ、製品一覧、製品詳細
- 必要性が確認された場合のお知らせ
- 編集可能な固定ページ
- 連絡先やSNSリンクなどの編集可能なサイト設定
- microCMSでの画像管理
- プロジェクト独自のデータベースを必要としない問い合わせ導線

## 明示的な承認があるまで対象外

- 会員アカウント
- 決済
- 予約
- ユーザー投稿
- 独自管理画面
- プロジェクトが所有するデータベース
- ブラウザからのmicroCMS API連携

## 未確定事項

- 公開時の優先言語は中国語、日本語、英語、または複数言語のどれか。
- どの既存製品、画像、PDF、仕様を移行してよいか。
- 公開時にお知らせ機能が必要か。
- microCMSで公開操作を行う担当者は誰か。
- 問い合わせフォームが必要か、送信先はどこにするか。
- 既存ロゴ、ブランドガイド、製品画像、製品カタログがあるか。
- どの連絡先情報が現在も正しく、公開承認されているか。
- 製品価格、販売代理店、認証、ダウンロード資料が必要か。
