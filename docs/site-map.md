# サイトマップ

## 状態

現行サイトをHTTP経由で確認して作成した下書き。構造とコンテンツは移行候補であり、公開用の確定文言ではない。

## 候補URL

| URL | 目的 | microCMSで編集 |
| --- | --- | --- |
| `/` | トップページ | 一部 |
| `/about/` | 会社紹介・技術紹介 | はい |
| `/products/` | 製品カテゴリ一覧・注目製品 | はい |
| `/products/[category]/` | 製品カテゴリ一覧 | はい |
| `/products/[category]/[slug]/` | 製品詳細 | はい |
| `/news/` | お知らせ一覧。必要な場合のみ。 | はい |
| `/news/[id]/` | お知らせ詳細。必要な場合のみ。 | はい |
| `/contact/` | 連絡先と承認済みの問い合わせ手段 | 一部 |
| `/privacy/` | プライバシーポリシー | はい |
| `/ja/` | 日本語トップページ | 一部 |
| `/ja/about/` | 日本語会社紹介 | はい |
| `/ja/products/` | 日本語製品一覧 | はい |
| `/ja/products/[slug]/` | 日本語製品詳細 | はい |
| `/ja/contact/` | 日本語連絡先 | 一部 |
| `/en/` | 英語トップページ | 一部 |
| `/en/about/` | 英語会社紹介 | はい |
| `/en/products/` | 英語製品一覧 | はい |
| `/en/products/[slug]/` | 英語製品詳細 | はい |
| `/en/contact/` | 英語連絡先 | 一部 |
| `/zh/` | 中国語トップページの互換URL | 一部 |
| `/zh/about/` | 中国語会社紹介の互換URL | はい |
| `/zh/products/` | 中国語製品一覧の互換URL | はい |
| `/zh/products/[slug]/` | 中国語製品詳細の互換URL | はい |
| `/zh/contact/` | 中国語連絡先の互換URL | 一部 |

## URLルール

- URLは小文字で、安定的かつ意味のある文字列にする。
- 公開URLを変更する場合は、リダイレクトを文書化する。
- 実装前に最終URLを確認する。
- 既存のトップ、会社紹介、製品、問い合わせ、連絡先という情報構造は保持しつつ、デザインと旧URLは刷新する。
- 中国語の正規URLはルート直下とし、`/zh/`配下は既存リンクを維持する互換URLとする。
