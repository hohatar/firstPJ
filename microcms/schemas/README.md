# microCMSインポート用APIスキーマ

このフォルダのJSONは、microCMSの「APIスキーマを定義」画面で読み込むための定義ファイルである。JSONはAPI単位で読み込むため、先にAPI名、エンドポイント、形式を指定してから対応するファイルを選択する。

| 作成順 | API名 | エンドポイント | 形式 | JSON |
| --- | --- | --- | --- | --- |
| 1 | 製品カテゴリ | `product-categories` | リスト形式 | `product-categories.json` |
| 2 | 製品 | `products` | リスト形式 | `products.json` |
| 3 | サイト設定 | `site-settings` | オブジェクト形式 | `site-settings.json` |
| 4 | 会社紹介 | `company-profile` | オブジェクト形式 | `company-profile.json` |
| 5 | お知らせ | `news` | リスト形式 | `news.json` |

## 注意点

- `products.json`は、互換性を優先した基本項目だけを含める。インポート後、次の4項目を管理画面から追加する。これは参照・繰り返し・複数ファイルの複合設定によるインポートエラーを避けるためである。
  1. `category`：コンテンツ参照、必須、参照先は`product-categories`。
  2. `gallery`：複数画像、任意。
  3. `documents`：複数ファイル、任意。
  4. `specifications`：カスタムフィールド「仕様項目」（項目名・仕様値を中国語／日本語／英語で各1つ）を作成し、繰り返しフィールドとして追加する。
- 公開・非公開の管理は、microCMSのコンテンツ公開ステータスだけで行う。独自の公開フラグは作成しない。
- 日本語・英語の必須項目は、翻訳を用意してからコンテンツを公開する運用を前提とする。旧サイトの移行CSVでは未翻訳の欄を空欄にしている。
- スキーマのインポートは新規API作成時に行う。既存APIに対しては「API設定」から変更する。
